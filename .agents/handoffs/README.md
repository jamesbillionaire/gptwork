# Handoff History

Use this folder for lightweight archived handoff snapshots only when they help the next agent understand unfinished or recently completed work.

`LATEST.md` remains the canonical current handoff. Git history remains the normal version history. Do not append long logs to `LATEST.md`; keep it current and concise.

## When to Archive

- Before replacing a substantial unfinished handoff.
- When pausing work that may resume in a later task.
- When a completed task contains decisions or verification details that should remain easy to find.

## Naming

Use:

`YYYY-MM-DD-short-task-name.md`

Example:

`2026-08-25-agent-handoff-system.md`

## Snapshot Contents

Keep each archived handoff brief:

- Status.
- Key decisions.
- Files changed or outputs produced.
- Verification performed.
- Blockers or risks.
- Exact next steps.
