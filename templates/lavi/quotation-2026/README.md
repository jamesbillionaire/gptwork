# LAVI Modern Quotation Template 2026

This package is the approved starting point for new general LAVI Technologies quotations.

## Files

- `LAVI_Modern_Quotation_Template_2026.docx` — editable Legal-size template.
- `LAVI_Modern_Quotation_Template_2026.pdf` — approved rendered reference for visual QA.
- `LAVI_New_Logo_2026.png` — official transparent logo asset.

## Brand and layout controls

- Page: Legal, 8.5 × 14 inches.
- Primary teal: `#03A5B0`.
- Primary navy: `#324F79`.
- Content width: `10,656 DXA` with 0.55-inch side margins.
- Pricing columns in DXA: `650 / 720 / 5,510 / 1,888 / 1,888`.
- Totals block: `6,880 DXA` left indent with `1,888 / 1,888 DXA` columns.
- Section headings must stay inside the content rail; no prefix line or border may protrude into a margin.

Full operating rules are in the repository root `AGENTS.md`.

## Release use

1. Copy the DOCX and replace all placeholders.
2. Preserve fixed pricing and totals column geometry.
3. Confirm commercial data, VAT treatment, references, and dates from approved sources.
4. Export to PDF and compare with the reference layout.
5. Render and inspect every page before delivery.
